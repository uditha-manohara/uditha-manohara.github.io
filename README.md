# Uditha Manohara Prasad: Portfolio

Static site for https://udithamanohara.dev/. Software Engineer and Founder & CEO of Neziora. Plain HTML, CSS and JavaScript with GSAP (CDN). Deploy by uploading these files to the root of the GitHub Pages repository.

- `index.html`: semantic page, full SEO metadata and JSON-LD (Person, Organization, Service, projects, FAQ)
- `style.css`, `script.js`: Neziora black / white / crimson (#FC0229) design, loading scene, GSAP animations
- `llms.txt`, `robots.txt`, `sitemap.xml`: crawler and AI-search discovery files
- Replay the loading scene any time: open `https://udithamanohara.dev/?intro` or press "Replay intro" in the footer
